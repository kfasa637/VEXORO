# VEXORA — Android starter project

**Интерфейс:** Minecraft Bedrock 1.26.32, чёрный / белый / графитовый стиль.

## Что внутри
- Полный исходный Android-проект на Java.
- Разделы Combat Practice, HUD, Utilities, Performance и Settings.
- Плавающая перетаскиваемая кнопка V и компактная демо-панель.
- Демонстрационные переключатели и безопасный чек-лист оптимизации.
- GitHub Actions workflow для облачной сборки debug APK.

## Важно
Это **заготовка интерфейса Android**, а не полноценный клиент Minecraft. Она не подключается к игре, не меняет память Minecraft, не автоматизирует атаки, не реализует KillAura и не повышает FPS внутри игры. Переключатели HUD — демонстрационные. Mace Helper — напоминание для тренировки, без автоматического боя. Некоторые приложения могут блокировать оверлеи.

## Как собрать APK с телефона через GitHub
1. Создай репозиторий GitHub `VEXORA`.
2. Загрузи содержимое ZIP так, чтобы `settings.gradle`, `build.gradle`, папка `app/` и `.github/` находились в корне репозитория.
3. Открой вкладку **Actions** и запусти **Build VEXORA APK** (или отправь изменения в ветку `main`).
4. Открой завершённый запуск workflow и скачай артефакт `VEXORA-debug-apk` в разделе **Artifacts**.
5. Распакуй скачанный архив — внутри будет `app-debug.apk`.

## Разрешение оверлея
Запусти приложение, нажми **Enable floating V button** и разреши отображение поверх других приложений в настройках Android. Нажми V, чтобы открыть демо-меню; перетаскивай кнопку, чтобы переместить её.
